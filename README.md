# Trabalho-Processamento-de-Sinais-I-6
CEFET/RJ
Disciplina: Processamento de Sinais I

Autores: Rawan Brasil Monteiro Cavalcante, Fabio Daniel dos Santos Lacerda.

## O projeto aborda conceitos fundamentais como:

| Conceito | Descrição |
|-----------|-----------|
| Filtros IIR de 2ª ordem | Projeto e análise de filtros digitais utilizando blocos básicos de segunda ordem |
| Resposta em frequência | Estudo do comportamento espectral dos filtros |
| Polos e zeros | Análise da estabilidade e seletividade dos sistemas |
| Estruturas em cascata e paralelo | Construção de filtros mais complexos a partir de blocos básicos |
| Quantização de coeficientes | Avaliação dos efeitos da precisão numérica nos filtros |
| Processamento de áudio | Remoção de interferências utilizando filtros digitais |

## Objetivos

| Objetivo |
|-----------|
| Projetar filtros passa-baixas, passa-altas, passa-faixas e rejeita-faixas utilizando blocos IIR de segunda ordem |
| Analisar respostas em frequência e diagramas de polos e zeros |
| Comparar diferentes estruturas de implementação de filtros digitais |
| Avaliar os efeitos da quantização dos coeficientes sobre estabilidade e desempenho |
| Desenvolver um sistema de filtragem para recuperação de sinais de áudio contaminados |
| Utilizar métricas como SNR e MSE para avaliar a qualidade dos resultados |
